Privacy Policy

Last updated: August 26, 2026

OHRANA Home Security is a private home security application operated for the owner's personal use.

Google Drive access

OHRANA uses Google Drive access only to manage the owner's OHRANA video archive.

The application may:

  • read file metadata required to identify archive files;
  • verify whether an archive file exists;
  • store file identifiers, names, sizes, checksums and operation status locally;
  • permanently delete specific archive files when explicitly requested by the owner;
  • verify that requested archive files were successfully deleted.

Storage of Google user data

OAuth credentials and archive metadata used by OHRANA are stored locally on the owner's Home Security computer. They are not stored in this public website or public GitHub repository.

Sharing of Google user data

OHRANA does not sell Google user data, use it for advertising, profiling, or marketing, or share it with unrelated third parties.

Data retention

Archive metadata is retained locally only as needed for security, archive verification, recovery, and deletion workflows.

Revoking access

The owner may revoke OHRANA's Google account access at any time through the Google Account security and permissions settings.

Google API Services User Data Policy

OHRANA's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For questions about this privacy policy, use the support email shown on the OHRANA OAuth consent screen.
